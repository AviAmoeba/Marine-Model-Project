# StrathE2E2 Harvest Optimisation


This project develops a computational pipeline for assessing whether specified harvest-ratio targets can be achieved within the StrathE2E2 ecosystem model by adjusting fishing-gear activity values. The pipeline formulates the problem as a non-negative linear system and combines analytical solutions, non-negative least squares, graph-based structural decomposition, connectivity and bridge analysis, and sensitivity analysis to determine whether targets are achievable and, when they are not, identify the closest feasible solution and the fishing activities, constraints, or power values that have the greatest influence on model feasibility.
